# Flash Auto テストケース一覧

## 1. 基本表示

| # | テスト内容 | 期待結果 | 確認方法 |
|---|----------|---------|---------|
| 1.1 | 初回アクセス | スプラッシュ画面→ホーム画面にサンプル3冊が表示される | ブラウザのlocalStorageを空にしてアクセス |
| 1.2 | リロード後のデータ保持 | 作成した単語帳がリロード後も残る | 単語帳を1つ作成→⌘+R→確認 |
| 1.3 | localStorageが壊れている場合 | サンプル3冊で正常起動（真っ白にならない） | DevToolsでlocalStorageに不正なJSON文字列を手動セット→リロード |

## 2. AI自動生成

| # | テスト内容 | 期待結果 | 確認方法 |
|---|----------|---------|---------|
| 2.1 | テーマ入力で生成 | 10〜15枚のカードが生成される | 「心理学入門」等を入力して生成ボタン |
| 2.2 | 空テーマで生成 | エラーメッセージが表示される | テーマ未入力で生成ボタン |
| 2.3 | 生成後の保存 | 単語帳がホーム画面に追加される | 生成→「この単語帳を保存」 |
| 2.4 | 続きを追加生成 | 5〜10枚のカードが既存に追加される | 生成後「続きを生成」ボタン |
| 2.5 | クレジット0で生成 | エラーメッセージが表示される | 3回生成後にもう1回試す |
| 2.6 | 生成後のカード編集 | 単語・定義を変更できる | 生成プレビューでカードをクリックして編集 |
| 2.7 | 生成後のカード削除 | カードが削除される（最後の1枚は削除不可） | 削除ボタン |
| 2.8 | 生成後のカード追加 | 新しいカードを手動追加できる | 追加フォームに入力 |

## 6. エラー耐性

| # | テスト内容 | 期待結果 | 確認方法 |
|---|----------|---------|---------|
| 6.1 | ErrorBoundary | エラー画面が表示され「もう一度試す」で復帰 | コンポーネント内でエラーを発生させる |
| 6.2 | AI全プロバイダー失敗 | 「すべてのAIサービスに接続できませんでした」表示 | 全APIを一時停止 |
| 6.3 | ネットワークオフライン | エラーメッセージが表示される（真っ白にならない） | ブラウザのDevTools→Network→Offline |
| 6.4 | localStorage容量オーバー | アプリは動き続ける（保存は失敗） | DevToolsでlocalStorageを5MB近くまで埋める |

## 8. Vercel Logs確認ポイント

| ログキーワード | 意味 |
|--------------|------|
| `[/api/groq]` | Groq APIのエラー |
| `[/api/ollama]` | Ollama接続エラー |
| `[/api/deck-cache]` | 単語帳生成・キャッシュのエラー |
| `[/api/track]` | ユーザー追跡のエラー |
| `[Groq API]` | Groq API自体のレスポンスエラー |
| `[ErrorBoundary]` | フロントエンドのクラッシュ |
| `[callAI]` | 全AIプロバイダー失敗 |
